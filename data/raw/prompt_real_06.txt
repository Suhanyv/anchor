# 真实用户提示词样本 06（视频 · 10 秒一镜到底 + 空间连续性硬约束）

来源：用户在网上找到的提示词（与 01–05 同类）。

体裁特征：**三段式连续镜头 + 空间连续性硬约束 + 三张参考图分工 + 声音设计**
核心叙事：放假空荡学校 → 沿围墙左移 → 杂货铺 → 老式 CRT 电视雪花点 →
         穿入屏幕 → 教室 → 停在拉小提琴的女生身旁
时长严格编排：6 秒 + 2 秒 + 2 秒 = 10 秒

原文：

---
【影片设定】

制作一段总时长10秒、16:9横向画幅的电影感连续镜头片段。

整体叙事：

放假的空荡学校 → 沿学校左侧围墙和同一条人行道向左移动 → 到达紧邻学校的杂货铺 → 聚焦店外老式电视机 → 电视机播放纯雪花点 → 镜头快速穿入电视机 → 进入学校教室 → 接近正在拉小提琴的女生并停在她身旁。

【空间连续性硬约束】

图一学校与图二杂货铺必须属于同一条街道、同一个夏日下午、相隔很近的两个地点。杂货铺位于学校正门左侧外墙的延长方向，距离学校约30米，店铺门面朝向与学校门口平行的人行道。

从00:00到00:07.5保持一条连续外景移动镜头，不硬切、不瞬移、不穿越墙体、不突然替换街道。

镜头移动路线必须清晰可见：

学校正门 → 左侧门柱 → 黑色铁栅栏和围墙 → 连续的树影、绿篱和人行道路面 → 杂货铺屋檐和树冠 → 杂货铺门口的电视机。

移动过程中，学校围墙、树木、斑驳阳光和同一段人行道至少持续出现在画面的一侧。杂货铺先从远处逐渐出现，再完整进入画面，不能从空镜中突然跳出。

 只负责学校起始环境。
 只负责同一条街道尽头的杂货铺环境和电视机。
 负责电视机内部连接到的教室，以及正在拉小提琴的女生。

时间：00:00–00:06，共6秒。

 。

00:00–00:02.6

从图一学校正门外的宽幅远景开始。黑色铁门敞开，校园内部空无一人，教学楼、树冠、公告栏和地面上的斑驳阳光保持清晰。镜头位于校门外，开始以平稳速度向左横向移动。

不要直接切到杂货铺。学校门柱从画面中央向右侧滑过，左侧逐渐露出学校围墙和黑色铁栅栏。

00:02.6–00:04.5

镜头继续沿同一条人行道向左移动。学校围墙、树影、绿篱和路面裂缝持续保持连续，画面左前方逐渐出现杂货铺的树冠、屋檐和门口货箱。

杂货铺必须看起来就在学校外墙左侧不远处，而不是另一个无关地点。背景中仍然能看到学校围墙或树冠，光线方向和色温保持不变。

00:04.5–00:06

镜头经过杂货铺外侧，店铺半开放式门面完整进入画面。货架、饮料箱、零食包装和木桌保持图二的生活感。店外左侧的老式CRT电视机亮起，屏幕显示纯黑白雪花点。

镜头从杂货铺整体平稳重新构图，焦点从店铺环境转移到电视机屏幕。不要出现店主、路人、学生或车辆。

运镜：

学校正门宽幅远景 → 沿左侧围墙持续横移 → 经过同一段人行道 → 杂货铺逐渐出现 → 平稳聚焦店外电视机。

展示重点：

学校与杂货铺之间的真实距离、连续围墙和树影、同一方向的夏日阳光、老式电视机的出现。

声音：

鸟鸣、树叶摩擦声、远处风声和轻微街道环境声保持连续。接近杂货铺时加入饮料箱轻微碰撞声和电视电流底噪。

【分镜02｜电视机雪花点 · 快速穿入】

时间：00:06–00:08，共2秒。
主体：店外老式CRT电视机。
效果：电视屏幕作为空间入口。

00:06–00:07.5

镜头缓慢推近电视机屏幕，持续1.5秒。电视机边框、玻璃反光和黑白雪花点逐渐放大，屏幕上的雪花点始终没有图像、人物、字幕、广告或Logo。

推近过程中，电视机外壳保持完整，不能提前进入屏幕。

00:07.5–00:08

在雪花点稳定显示1.5秒后，镜头突然快速穿入电视机。先短暂保留黑色电视边框和玻璃反光，随后雪花点迅速放大并充满整个画面，直接连接到教室内部。

转场不能出现爆炸、玻璃破碎、黑洞、随机故障闪烁或人物变形。快速穿入必须像镜头穿过一个真实发光屏幕。

运镜：

缓慢推近CRT屏幕 → 雪花点占满画面 → 快速穿入电视内部。

展示重点：

电视机屏幕的纯雪花点、1.5秒等待时间和明确的空间穿入效果。

声音：

电视电流声逐渐增强。00:07.5开始出现短促的噪声拉伸和快速穿行声，原有杂货铺环境声在穿入瞬间消失。

【分镜03｜教室中的小提琴】

时间：00:08–00:10，共2秒。
环境与人物：参考 
 。

00:08–00:09.3

镜头从雪花点中穿出，进入学校教室。教室靠窗，光线柔和偏白，空气中有轻微尘埃光束。女生坐在靠窗位置，正在拉小提琴。

镜头先看到她的侧后方、小提琴琴身和琴弓，然后继续向前推进。琴弓持续平稳地在琴弦上移动，左手自然按弦。女生专注演奏，不看镜头，不突然停止。

00:09.3–00:10

镜头越来越近，最后停在女生身旁的侧面近景，画面同时看见她的侧脸、小提琴、琴弓和窗边光线。

镜头在00:10停止推进，保留女生拉出长音的瞬间。不要追加对白、字幕或其他人物。

运镜：

电视机内部穿出 → 教室后方推进 → 沿小提琴琴弓方向接近 → 停在女生身旁。

展示重点：

从电视雪花点进入教室的连续转场、女生的侧脸、小提琴演奏动作、琴弓和窗边柔光。

声音：

进入教室后电视雪花噪声迅速消失，只留下小提琴真实演奏声、琴弓摩擦声和轻微教室环境底噪。00:10保留琴声余韵。

【全片摄影、剪辑与声音要求】

前7.5秒必须是一条连续外景移动镜头，学校到杂货铺之间通过围墙、围栏、树影、路面和同一方向的阳光建立空间连续性。杂货铺不能突然出现，不能使用硬切拼接两个地点。

电视机从00:06开始缓慢推近，持续1.5秒后才快速穿入。进入教室后继续向前推进，最后停在女生旁边。

保持真实摄影质感、自然光、轻微胶片颗粒和夏日下午的暖色调。图一、图二、图三只作为环境、构图和人物演奏状态参考，不复制图片边框、水印或额外文字。

总时长严格编排为：

学校沿外墙移动到杂货铺6秒＋电视机推近并穿入2秒＋教室接近小提琴女生2秒＝10秒。
