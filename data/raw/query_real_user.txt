# 真实用户 query 收集

用途：把训练数据从「模板句式」换成「自然句式」。

为什么需要它（实测依据）
------------------------
同一个模型、同一份语料：

    模板句式 query     86% 命中
    自然句子 query     41% 命中

差 45 个百分点。不是模型容量问题，是**训练 query 全是模板生成**，
模型学到的是关键词对齐；自然句子里关键词不一定对齐，优势就没了。
详见 `CORRECTIONS.md` C5。

怎么填
------
**一行一条，怎么打就怎么写，不要修饰。**

- 不要补全、不要改成书面语、不要补标点
- 短的更好（5~15 字的最稀缺，也最难）
- **答错的那些最有价值** —— 你印象里「这都查不出来？」的，优先记

三档都要，但优先级是：短（随口打的）> 中（带一两个修饰）> 长（带运镜和光）
