# 快速上手

**16 个参数里，你只需要动 3 个：**

```
① 中文描述    你想拍什么，用大白话写
② 任务        文生视频（默认）/ 图生视频 / 参考生视频
③ 输出格式    「自动（识别平台）」（默认）——写了平台名它自己认
```

其余 13 个都有能用的默认值，**先别动**。

---

## 用法一：我只想要一段英文风格片段

**参数**：`输出格式` = 片段（英文）

**输入**：`雪林里女子拉弓搭箭，冷白风雪`

**得到**：
```
in the style of Robert Eggers, candle-lit darkness, harsh snow light, ...
```

**接哪**：粘到任何 `CLIPTextEncode` 后面。这是最保险的一档，什么模型都吃。

---

## 用法二：我要即梦能直接用的中文提示词

**参数**：`任务` = 文生视频，`输出格式` = 自动（识别平台）

**输入**：`用 sd2.5 做一个骑士站在石地中央，手按长剑剑柄`

**它会**：
1. 从描述里认出「sd2.5」→ 即梦
2. 检索到风格（乌尔善：军阵/黄昏/尘土）+ 道具（长剑）
3. 按即时官方四段式输出

**得到**：
```
乌尔善：军阵、黄昏、尘土、横移。21:9。

一句话概述：骑士站在石地中央，手按长剑剑柄。

0–1 秒：…

摄影层：中景深；干净的数码质感；暖金；紧绷；50mm 标准。
只使用<环境声>，不要配乐，不要字幕。
不要出现：<2-4 个会让这条废掉的错误>。
```

**怎么读**：`<...>` 里的东西是**它不知道、要你补**的。
它不猜——猜错的破坏力比留空大（见 [CORRECTIONS.md](../CORRECTIONS.md) C6）。

## 用法三：我有首帧图，让它动起来

**参数**：`任务` = 图生视频

**输入**：`她缓慢转头看向镜头`（**不要写画面长什么样**）

**得到**：
```
【动作时间轴】
0–2 秒：<写：谁做什么、往哪个方向动、幅度多大>。
2–5 秒：<写：动作怎么继续或停下>。

【镜头】镜头极缓推近，只一种运动，不切镜。

【保持不变】主体、构图、光线、色调与首帧一致。
```

**为什么不让你描述画面**：首帧已经给了外观。再描述一遍 = 给模型两个来源 = 它会把首帧重画。
**外观槽位是故意留空的。**

## 用法四：我要三个镜头的分镜

**参数**：`任务` = 文生视频，`输出格式` = 自动，`提案分镜` = **True**

**输入**：`一个骑士手握一把长剑，和一群人交战，想要三个镜头`

**得到**：共用块 + 三拍 + **三段可直接粘的完整提示词**

```
【镜头 1】（3 秒 · static）…
【镜头 2】（5 秒 · strong）…
【镜头 3】（4 秒 · action）…
```

**三件要注意的事**：

1. **三镜要一次问全。** 逐镜单独问，它会各检索各的风格——三镜三种美术方向，剪不到一起。
2. **共用块要贴进每一段。** 即梦一次只出一镜，不贴就各找各的色调。
3. **时长是它按运动幅度分的**：静态 3 秒、动作 4 秒、强动作 5 秒、变形 6 秒。
   想改就改 `data/raw/duration_ref.json`，不用改代码。

## 时长要两头卡，不只是上限

```
平台上限 > 内容需要   →  缩短，别让它自由发挥
平台最短 > 内容需要   →  补一个动作副拍，不能硬撑
```

**两头都会坏，只是坏法不同。**

真实案例（骑士镜 1，4 秒）：时间轴里只写了一个"手指动了一下"，
剩下的秒数模型自己找事做——**镜头摇到脚上，最后停在一块空地上**，
主体整个丢了。

所以：

- 写满 4 秒要 **3 个动作**（掀披风 / 抬眼 / 松手再握），不是 1 个
- **机位要写死**：`机位固定在腰高，禁止下摇、禁止离开主体`
- **把"空镜、只有地面、主体走出画面"放进 negative**——不写它真敢给你

工具在"平台最短 > 内容需要"时会自己提醒这一句（v0.1.43 起）。

## 三个常见疑问

**Q：为什么输出里还留着 `<...>`？**
那是它**明确知道**自己不该猜的部分。填了它才完整。

**Q：调试信息里那句"风格置信度低"是什么意思？**
库里没有可靠匹配，输出里的风格一栏是占位符而不是推荐。**这时候风格得你自己定。**

**Q：为什么它不给我编动作？**
因为编出来的三段一定重复。它只给结构（建立/交手/收）和时长，动作是你的。
